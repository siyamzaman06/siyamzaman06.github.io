SIYAM ZAMAN ENGINEERING PORTFOLIO

Static mechanical engineering portfolio hosted on GitHub Pages.

PAGES
- index.html: home, about, contact, and links to every category
- additional-projects.html: coursework and class projects
- school-projects.html: redirect to additional-projects.html
- fsae.html: Formula SAE drivetrain design and testing
- personal-projects.html: independent practice and personal builds
- cooling-test-bench.html: project overview, CFD results, prototype assembly, and planned tests
- planetary-gearbox.html: gearbox calculations and plans for design and testing
- certifications.html: completed certifications and technical training

GITHUB PAGES
Keep the HTML, CSS, JavaScript, and assets folder at the repository root. The homepage must be named index.html. GitHub Pages serves the files directly; there is no build step. Keep private documents and local browser profiles out of the published files.

CONTENT STATUS
When an image is not ready, show a short status message. Label unfinished work as in progress, pending, or planned. Keep simulation predictions separate from measured results.
